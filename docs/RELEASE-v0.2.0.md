S1 Voice Bridge 的首个公开实验版本，面向 Apple Silicon Mac。

本版加入：

- 记住上次成功连接的 S1，App 启动和麦克风唤醒后自动连接。
- 主动断开暂停重连，蓝牙和电脑休眠恢复、失败退避。
- 菜单栏后台运行，窗口关闭后继续等待麦克风。
- 保存 Fn、自定义快捷键、音频输出和联动开关，兼容旧版设置。
- 新 App 图标，内置可迁移的 Python 3.12 运行环境。

下载 `S1-Voice-Bridge-v0.2.0-macOS-arm64.zip`，内含 App、虚拟音频安装包和中文说明。`SHA256SUMS.txt` 可用于核验下载文件。

运行前请自行安装官方讯飞语音助手，已验证版本为 4.4.36.4；测试时退出助手，保留安装文件。讯飞代码、动态库和账户不在本发布包中。

原始 S1 收音、按钮和豆包输入链路已在用户设备上跑通。自动重连与设置迁移通过离线测试，发布 ZIP 解压换目录后自检通过；新增自动重连尚需多轮真实开关/休眠验收，因此标记为 Pre-release。

当前为 ad-hoc 签名、未公证。升级后若辅助功能开关已开但仍提示未授权，请移除旧条目，再添加固定 `/Applications` 位置的新 App。首次音频驱动安装后若设备未显示，请重启音频服务或 Mac。
