S1 Voice Bridge v0.2.1 换上白发眨眼、橙蓝耳麦的新角色图标，应用图标、窗口标题区域和仓库首页同步更新。

本版包含 v0.2.0 的蓝牙自动连接、菜单栏后台运行、设置保存和便携 Python 3.12 运行环境。蓝牙、收音和快捷键逻辑与 v0.2.0 相同。

下载 `S1-Voice-Bridge-v0.2.1-macOS-arm64.zip`，内含 Apple Silicon / macOS 13+ App、虚拟音频安装包和中文说明。`SHA256SUMS.txt` 用于核验下载文件。已安装 S1 Bridge Audio 的用户无需重复安装音频组件。

运行前请自行安装官方讯飞语音助手，已验证版本为 4.4.36.4；使用时退出助手，保留安装文件。讯飞组件不随包分发。

当前使用 ad-hoc 签名、未做 Apple 公证。升级后若反复提示辅助功能授权，请移除旧条目，再添加 `/Applications/S1 Voice Bridge.app` 中的新版本。

本次发布已检查 10 个图标尺寸，应用签名、原生离线自检和 ZIP 解压换目录后的运行检查通过。

原始 S1 收音、按钮和豆包联动已在用户设备上跑通。自动重连仍待多轮真实开关和休眠验收，因此继续标记为 Pre-release。验证范围见仓库 `docs/VERIFICATION.md`。
